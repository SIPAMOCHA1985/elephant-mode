# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, give and accept constructive feedback, and focus on what's best for the community. Harassment, insults and personal attacks are not tolerated.

Report unacceptable behavior through GitHub's *Report content* feature or by opening a private security advisory on this repository. Reports are handled confidentially.
